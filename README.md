# E-commerce-Sales-Performance-Dashboard

An interactive Power BI dashboard that turns raw e-commerce order data into sales, profit, and regional insights using Power Query, data modeling, and DAX.

An online retailer has order data spread across separate files and no single view of its business. Management needs to answer questions such as:

How are sales, profit, and quantity trending month over month?
Which states and sub-categories are the top performers?
Which product categories and payment modes drive the most orders?

This project consolidates the data into one interactive dashboard so these questions can be answered quickly and filtered by quarter and state.
